# FITBOX

App para administrar el gimnasio FITBOX: clientes y planes, agenda, dinero (efectivo y BAC), cuentas bancarias para copiar, código de acceso, mantenimiento e insumos.

- Se abre en el navegador y se instala en el iPhone desde Safari: **Compartir → Agregar a inicio**.
- Los datos viven en Supabase, protegidos con inicio de sesión. Este repositorio solo tiene el diseño de la app, ningún dato.
- `supabase/schema.sql` crea la tabla y sus reglas de acceso.
- `config.js` lleva la dirección del proyecto de Supabase y su llave pública.
- Fuentes: Futura para títulos (viene en iPhone y Mac; en otros equipos se usa Jost, libre y muy parecida) y Metropolis para el texto. Las dos libres van en `fonts/`.
- Colores de marca: #FAA300, #000000, #4B4B4B, #EBEBEB.
